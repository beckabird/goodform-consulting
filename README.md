# GoodForm Consulting

Marketing site for GoodForm Consulting, an affiliate of Solvhaus Solutions and Karle Kreatives.

- Static site: `index.html` with `logo.png` and `adelle.jpg`. No build step.
- Pages (Home, Services, eight service pages, Approach, Adelle, Insights, Contact) are views inside `index.html`, switched by the nav.
- `vercel.json` sends `X-Robots-Tag: noindex` while the site is in review. Remove that header at launch.
